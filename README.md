# Metrajes 404

This is a simple static homepage for a retro, early-YouTube-inspired horror video archive.

Files included:
- `index.html` – page structure and content
- `styles.css` – retro design and layout styling
- `script.js` – video card data and rendering

Quick preview:
1. Open `index.html` directly in a browser, or
2. In a terminal, run:
   `python -m http.server 8000`
3. Then open: `http://localhost:8000`

What to customize next:
- Replace the demo video list in `script.js` with your own videos
- Change the branding text and colors in `index.html` and `styles.css`
- Add a real upload page or admin-only dashboard later

This is just a foundation. You can expand it into a full website later with:
- user login and uploader permissions
- video detail pages
- actual uploaded video files
- a backend database
